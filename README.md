# nisaba.wynter.ai

The one-page site for [Nisaba](https://github.com/WynterJones/Nisaba).

Static HTML, CSS and ~10 lines of JS. No build step, no dependencies.

```bash
python3 -m http.server 4000   # or: npx serve .
```

Deployed on Netlify from this directory (`publish = "."`).

Illustrations are original fox-spy artwork in the spirit of 1960s MAD-magazine
caper cartoons — black-and-white ink and halftone, brand purple used sparingly.
